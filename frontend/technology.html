A. Dual-Stream AI Architecture

SPATIO-TEMPORAL FUSION
CNN

EfficientNet-B0

Visual Spatial Feature Extraction

Employs compound scaling across network depth, width, and input resolution. MBConv (Mobile Inverted Bottleneck Convolution) blocks with Squeeze-and-Excitation optimize detection of GAN blending seams, boundary warping, and synthetic color cast without excessive parameter overhead.

Embedding Dim: 1,280 features
Input Tensor: 224×224×3 RGB
RNN

Bidirectional LSTM

Temporal Pattern Sequence Modeling

While spatial CNNs analyze isolated frames, deepfakes suffer from inter-frame flicker and physiological violations (irregular eye blinks, unnatural pulse dynamics). Our bidirectional LSTM processes sequence vectors in both forward and backward time steps to flag temporal inconsistencies.

Hidden Units: 256 units
Window Stride: 16 face frames

OpenCV Frame Pipeline

High-efficiency hardware-accelerated video decoding. Extracts uniform strides, handles variable frame rates (VFR), and prepares pristine uncompressed tensors for facial cropping.

Sub-sampled stride: 15 fps decimation

PyTorch & Cloud GPU Engine

Trained on a Kaggle T4 GPU with mixed precision. The website runs the same PyTorch model for inference; the analysis time of every scan is measured and shown in its report.

Cloud Architecture: Python • Torch • MySQL
