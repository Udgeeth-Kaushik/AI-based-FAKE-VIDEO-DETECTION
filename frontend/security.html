Security & Privacy Policy

Forensic media verification requires strict ethical boundaries, zero data harvesting, and hardened role-based infrastructure.

✔

Video Deleted After Analysis

The uploaded video file is deleted from the server as soon as the analysis finishes. Only the report and the suspicious-frame images are kept in your own history, and you can delete them any time.

◇

Private Per-User History

Every scan, report and frame image belongs to the account that uploaded it. Other users cannot open it, and the server checks ownership on every request.

◎

MFA & Access Control

Passwords are stored as salted scrypt hashes. The administrator account is protected by Two-Factor Authentication (TOTP 6-digit code), accounts lock after repeated failed logins, and sessions expire after inactivity.

Human-in-the-Loop Forensics Disclaimer
