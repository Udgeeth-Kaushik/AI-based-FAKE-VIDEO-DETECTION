# FVD THE REAL
## AI-Based Fake Video Detection System

An AI-powered fake video detection application using
machine learning and video analysis.

### Features
- Video Upload
- Deepfake Detection
- Face Analysis
- Automated Prediction
- Detection Results

### Technology
- Python
- Streamlit
- PyTorch
- OpenCV
- FaceForensics++

### Project Structure
- app.py
- common.py
- detector.py
- model/
- .streamlit/

### Installation

pip install -r requirements.txt

### Run Application

streamlit run app.py

### Disclaimer
Predictions are AI-generated and should not be treated
as definitive proof of video manipulation.
